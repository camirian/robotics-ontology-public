# Robotics Ontology Operating Standard

## 1. Role of This Repo
This repo is the glossary and terminology reference for robotics projects.

## 2. Standards
- Keep definitions concise and queryable.
- Keep acronyms and cross-links explicit.
- Keep the glossary consistent across projects.
- Keep the terminal baseline simple.

## 3. Documentation Rules
- `README.md`: glossary overview.
- `sysml_v2_models/README.md`: model library notes.

## 4. Quality Bar
- No definition drift without an update.
- No hidden abbreviation meaning.
- No undocumented reference assumption.
